# Medicore-HMS# MediCore | Healthcare Management System

MediCore is a professional C++ Healthcare Management System (HMS) developed with a custom Graphical User Interface (GUI) using SFML. Designed for modern clinical environments, it streamlines the interaction between patients, doctors, and hospital administrators through a secure, multi-portal architecture.

## Key Functionalities

### Administrative Dashboard (System Control)
* **Staff Management:** Add new doctors to the hospital database or remove existing staff.
* **Patient Oversight:** View comprehensive lists of all registered patients and their current accounts.
* **Financial Auditing:** Track unpaid bills and monitor total hospital revenue.
* **Patient Discharge:** Process patient departures by archiving medical records to a permanent history file.
* **System Security:** Access real-time security logs to monitor login attempts and system events.
* **Operational Reports:** Generate daily summaries of completed appointments and total earnings.

### Doctor Portal (Clinical Management)
* **Schedule Management:** Access a dedicated view of daily appointments and time slots.
* **Patient Diagnosis:** Look up patient medical histories to provide informed care.
* **Appointment Status:** Update status from "Pending" to "Completed" or "No-Show."
* **Digital Prescriptions:** Generate and store electronic prescriptions including medication names and clinical notes.

###  Patient Portal (Self-Service)
* **Instant Booking:** Schedule appointments based on medical specialization and doctor availability.
* **Personal Health Record:** Access individual medical history and view previous prescriptions.
* **Billing & Wallet:** * Monitor current balance and top up funds via a virtual wallet.
    * View all historical invoices and pay outstanding bills instantly.
* **Appointment Control:** View upcoming visits or cancel existing bookings.
